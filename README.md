# Redmind Security

Generated website workspace for the Golden Ratio Website Design Studio.

Start or resume work from HANDOFF.md, then follow the linked specification and the root START-HERE.md protocol.

## Contract

- Root user inputs are copied into inputs/user-submitted/; the original root package remains unchanged.
- Raw imported inputs remain ignored by Git; inputs/INPUT-INVENTORY.json is the trackable review record.
- Additional approved local inputs may be recorded in the inputs directory.
- Only approved delivery assets should be promoted into version-controlled website source.
- All files for this website stay under `output/redmind-security/`.
- Design sources live in `designs/`.
- Pencil and generated exports live in `exports/`.
- Implementation lives in `src/`.
- Spec Kit artifacts live in `specs/`.
- Visual QA artifacts live in `tests/visual/`.

Do not share tokens, brand assumptions, or one-off implementation state with other generated websites unless that work is promoted back into the root studio deliberately.
